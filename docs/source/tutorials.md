# Jupyter tutorials

Every tutorial is available in **English** and **中文**. The paired notebooks use the same input data and calculation calls. Run them from the project root or their `tutorials/en/` and `tutorials/zh/` folders.

| Topic | English | 中文 | Local input |
|---|---|---|---|
| Single-period Brinson and reports | [Open notebook](../../tutorials/en/single_period_attribution.ipynb) | [打开教程](../../tutorials/zh/single_period_attribution.ipynb) | `data/dow30_brinson/` |
| Multiple-period Brinson and linking | [Open notebook](../../tutorials/en/multiple_period_attribution.ipynb) | [打开教程](../../tutorials/zh/multiple_period_attribution.ipynb) | `data/dow30_brinson/` |
| Dow 30 interactive workflow | [Open notebook](../../tutorials/en/dow30_brinson_interactive.ipynb) | [打开教程](../../tutorials/zh/dow30_brinson_interactive.ipynb) | `data/dow30_brinson/` |
| Multi-account attribution | [Open notebook](../../tutorials/en/multi_account_attribution.ipynb) | [打开教程](../../tutorials/zh/multi_account_attribution.ipynb) | `data/multi_account/` |
| Behavioral Alpha Frontier research model | [Open notebook](../../tutorials/en/behavioral_alpha_frontier.ipynb) | [打开教程](../../tutorials/zh/behavioral_alpha_frontier.ipynb) | `data/baf/` |

The single-period tutorial has no temporal linking. The separate multiple-period tutorial compares Cariño, GRAP, Frongello, Menchero, and Geometric linking and labels every linked chart. The Dow 30 workbook and reports remain available under `outputs/dow30_brinson/`.
